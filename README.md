# SAP Stammtisch Dortmund

Website for the SAP Stammtisch Dortmund: <https://sapstammtisch.github.io/Dortmund/>

## Images

Photos are optimized automatically (resized to 2048 px, EXIF stripped). Run
`python3 scripts/optimize_images.py` after adding images; originals are kept
once in `img/originals/` (not served). The dev container and GitHub Actions
install Pillow / run it automatically.
